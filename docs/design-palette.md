# Nola Kitchen — Food-led Color Palette

Website menggunakan tiga core colors agar identitas visual lebih fokus dan tidak terasa seperti template generik.

- Chili Red — `#B73A24`: primary CTA, highlight harga/best seller, dan elemen yang perlu menarik perhatian.
- Roasted Brown — `#2A1712`: typography, dark section, secondary action, dan visual depth.
- Warm Cream — `#FFF5EC`: background utama agar produk makanan tetap terasa hangat.

Semua variasi lain menggunakan opacity/tint dari tiga warna tersebut, ditambah putih sebagai surface netral.
