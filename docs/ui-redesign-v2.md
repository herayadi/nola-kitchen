# Nola Kitchen UI Redesign V2

Reference direction: Gojek's current public website is used as a reference for design discipline, not copied visually.

## Principles
- Strong hierarchy, fewer competing components.
- One primary CTA color: sambal red.
- Dark roasted-brown for high-contrast hero/footer/ordering section.
- Warm rice-cream as the base background.
- Consistent 12-16px control radii; avoid making every element a pill/card.
- Menu is presented as a catalog/list, not a repeated SaaS-card grid.
- Sections use different composition rhythms instead of repeating three-column cards.
- No fabricated food photography or testimonials before real assets/data exist.

## Core palette
- Sambal Red: #D84A2F
- Roasted Brown: #211410
- Rice Cream: #FFF7EE
- White is used only as a neutral surface.

## Primary flow
Hero -> Menu -> Cart -> WhatsApp -> Admin confirms -> Admin orders ojol.
